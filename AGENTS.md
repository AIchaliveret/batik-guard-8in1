# AGENTS - 4 Agen Otonom
1. Agent Level dan Tekanan: baca Sight Glass + Pressure Gauge + Pressure Sensor, alarm jika turun ke 50%
2. Agent Daur Isi Ulang: atur 4 tahap 50-75L lewat Solenoid Valve, tutup jika sudah 60%/80%
3. Agent Sirkulasi dan Suhu: pantau 3 tingkat di Pendukung, pastikan thermosiphon jalan tanpa motor
4. Agent Listrik dan Logbook: catat RPM 2800, Watt 2400-3000 DC, simpan log harian
